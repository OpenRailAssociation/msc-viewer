# Roadmap

## Current Status

MSC Viewer is an open-source web application for visualizing and analyzing
GSM-R MSC/MSS configurations.

The project is part of the OpenRail Association.


## Now

- OpenRail integration and project setup
- Deployment and installation improvements
- Update open-source dependencies
- OAuth authentication and authorization: role-based access control and pluggable authentication


## Next

- Write access to the MSC/MSS: execute generated commands with review and audit trail
- Pluggable AI providers (OpenAI, Anthropic, Amazon Bedrock)
- Enhance natural-language queries
- Automated, time-triggered data loading from MSC instances


## Later

- AI-assisted configuration analysis
- Automated configuration validation
- Externalized configuration: define config types and relations without recompiling (JavaConfig->JSON/YAML)
- Migration to Vercel AI SDK.


## Community

Ideas and contributions are welcome. 
Please create an issue to discuss larger features before starting implementation.
